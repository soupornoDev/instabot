# Instagram Media Manager

A secure, performance-oriented terminal automation framework built using Python 3 and `instagrapi` for Android Termux.

## Setup Instructions
```bash
pkg update && pkg upgrade -y
pkg install python git libjpeg-turbo unzip clang make -y
termux-setup-storage
unzip instagram_media_manager.zip
cd instagram-media-manager
pip install -r requirements.txt
python main.py
```
